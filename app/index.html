STEP 1

Check & Install Required Apps / Drivers

  1. Click the Apps & Drivers tab (or click the button below).
  2. Review what is already marked Installed in green on your PC.
  3. Click Select Missing to check any missing tool (OpenCode V2, Node.js, Git, Python/uv, Graphify, REA 6.8.0, or Android ADB USB drivers).
  4. Click Install Selected Apps / Drivers — progress streams live in the bottom console!
STEP 2

Add API Keys & Auto-Scan Models Inside Your Key

  1. Open the AI Keys & Scanner tab.
  2. Click Get Key on any free provider card (Google AI Studio, OpenRouter, Groq, Cerebras, SambaNova, Mistral) to get a free key.
  3. Paste 1 key or multiple keys (one per line for Multi-Key Pooling).
  4. Click 🔍 Scan Key (or 🔍 Scan & Read All Models in My API Key) — the app reads every model unlocked by your key and shows them as clickable chips!
STEP 3

Pick Free Coding Models & Enable Non-Stop Auto-Switch

  1. Open Free Models (Best → Low) to browse the top ranked free coding models (S+ Tier → B Tier) plus live $0 OpenRouter models.
  2. Click Use Model on your favorite model, or click ⚡ Use Smart Gateway in OpenCode on the left shelf.
  3. Open Combo Router to view or reorder your fallback list. When Model #1's free quota finishes (HTTP 429), the app automatically switches to Model #2 so you never stop working!
STEP 4

Import Any Skill or Plugin in the World

  1. Open World Skills & Plugins.
  2. Click ⇄ Sync All Skills on PC to automatically import skills from Claude Code, Codex, Gemini, and OpenCode.
  3. To import a skill from anywhere on the web: paste any GitHub repo (owner/repo), raw URL (SKILL.md, CLAUDE.md, AGENTS.md, .cursorrules), or raw text, and click ★ Import & Convert Skill for All Agents.
  4. To add a plugin, type its npm name or file path under Universal Plugin Installer and click Install Plugin.
STEP 5

Sign In (GitHub / Google) & Sync Across PCs

  1. Open the Cloud Sync tab.
  2. Sign in with GitHub (syncs to a private secret GitHub Gist) or Google (syncs to your Google Drive / OneDrive folder).
  3. Enter an optional secret passphrase to encrypt your API keys with AES-256-GCM.
  4. Click ☁ Save Work to Cloud Now on PC #1, and click ⬇ Restore Work from Cloud on PC #2!
STEP 6

Start a Project, Connect All IDEs & Report Bugs

  1. In Gateway Overview, browse to any drive (C:, D:, E:, F:), type a skill topic (e.g. godot or react), and click Create Project & Find Skill.
  2. Click 🔗 Connect All IDEs (:4141/v1) on the left shelf to route OpenCode, Claude Code, Codex, Cursor, and Cline through the local gateway.
  3. If any error ever occurs, open Bug Reporter and click 🐞 Send Issue to GitHub Repo Now (secrets are automatically redacted).
